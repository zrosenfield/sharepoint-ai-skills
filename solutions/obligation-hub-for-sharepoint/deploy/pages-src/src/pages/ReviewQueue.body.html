Review queue

Capture holds anything it isn’t sure about. Check the clause, then accept, edit or exclude each item.

What the three actions do

Accept
Opens the item to edit. Set Review to Confirmed and save — it then gets an owner and reminders like any other obligation.
Edit
Fix the party, date, category or wording first, then set Review to Confirmed.
Exclude
Opens the item in the list. Select it and use the Remove obligation quick step: it takes the obligation out of tracking and adds the clause to Exclusions so capture won’t add it back.
