Settings

Everything that drives the hub: who owns what, what gets tracked, the AI workflows and their run history. For site owners and contract managers.

Lists and libraries

Open a list to change it. Changes take effect on the next workflow run.

  • Obligation Owners Routing rules: category, business unit and counterparty → owner, escalation owner and how they’re notified. The most specific rule wins. Routing rules
  • Obligation Types What counts as an obligation: track, exclude or hold for review, with default risk and recurrence for each type. Capture uses this to classify
  • Exclusions Clauses and patterns people removed, so capture doesn’t add them back — for one contract or all of them. Filled by the Remove obligation quick step
  • Run Log One row per automated run: what ran, the outcome, what it created, updated or held, and the details. Run history
  • Evidence Proof that obligations were fulfilled — sent notices, reports, certificates. Linked from each obligation’s Evidence field. Document library
  • AgentAssets (skills) The site’s skills, in Skills/<skill-name>/SKILL.md. Copilot in SharePoint and the AI workflows load them. 5 skills, used by 6 workflows
  • Contracts library settings Columns that fill in automatically from each contract, versioning and permissions for the Contracts library. Library settings
  • Obligations Every tracked obligation with its owner, status, timing, review state and evidence. Views for my items, needs owner and needs review. The tracking list

Configuration

hub-settings.json in AgentAssets/Config holds the company name, the due-soon window, the reminder cooldown and the leadership digest recipients. The workflows use these settings.

These pages can’t read the file, so they always show Due soon as within 14 days.

Workflows

Six AI workflows keep the hub current, each with one trigger. Create each one by pasting its setup prompt into Copilot in SharePoint on this site. Each loads its skill from AgentAssets and logs every run; the two capture workflows share one skill.

Reminders and digests are sent as the person who set up the workflows. Set them up with a shared obligations account so messages don’t depend on one person’s mailbox.

  • Capture new contracts

    Reads each newly added contract, classifies its clauses using Obligation Types and Exclusions, and creates its obligations. Anything it isn’t sure about is held for review.
