# Prepare and share content with a customer

1. **Identify** the file(s) and the recipient email address(es). Ask only if a recipient is missing or ambiguous.
2. **Check shareability** for each file (Content Library or Generated Content):
   - Internal only -> stop. Explain why, and suggest a customer-shareable alternative from the Content Library.
   - Customer-shareable (NDA) -> confirm the customer has an NDA before sharing (ask the seller if unknown).
   - Public -> OK.
   - Expired (Expires on is past) -> stop and point to the replacement if Archive lists one.
3. **Share** with specific-people **view** links only, never "Anyone" links. Do not write the email message for the
   seller; send only text the seller typed, or no message.
4. **Log** one row per recipient in **Customer Shares**: Share title, Customer, Recipient email, Shared copy (link),
   Source asset (link), Shareability, Shared on = today, Status = Active, Opportunity if given.
5. Reply with what was shared, with whom, the access level, and whether an email was sent.
