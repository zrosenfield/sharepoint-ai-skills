# Six Design Languages: AI Website Inspiration Playbook

**Purpose:** A reusable creative-direction document for generating six visually distinct versions of the *same* website or application page. Use these as broad design philosophies inspired by the careers and approaches of six influential designers—not as instructions to copy existing artwork, proprietary interfaces, signature compositions, or branded assets.

## 1. How to use this document

Attach this document to an AI coding or design agent along with a screenshot, URL, source code, Figma design, or description of the page you want to redesign.

**One-line request:**

> Build six versions of this page, one for each design language in the attached *Six Design Languages* playbook. Keep the underlying content, functions, and user journeys equivalent, but make the six experiences unmistakably different. Show me a comparison page where I can switch among them.

**Optional targeted request:**

> Redesign this page using Design Language 03 (Interactive Systems / Yugo Nakamura influence). Preserve all important behaviors and content; apply the art direction, layout, interaction, typography, and accessibility rules in the playbook.

### Nonnegotiable rules for the AI

1. **Same product, six interpretations.** Preserve core content, semantic structure, navigation destinations, data, workflows, and functional requirements. Do not hide or delete functionality merely to achieve a look.
2. **Different visual *systems*, not just different color themes.** Vary typography, hierarchy, grids, spacing, imagery, UI components, backgrounds, visual metaphors, hover/focus states, and motion. Each variation should be identifiable in grayscale.
3. **Take inspiration, do not imitate.** Work from transferable principles rather than recreating a designer's recognizable works, iconic brand assets, one-to-one layouts, or existing website designs. Do not present the output as endorsed by or authored by any named designer.
4. **Keep it real and useful.** Design actual navigation, forms, tables, settings, search, empty states, and responsive views as the page requires—not just striking hero sections.
5. **Accessibility is a requirement.** Target WCAG 2.2 AA where applicable: readable contrast, clear focus states, keyboard usability, labels, appropriate touch targets, and reduced-motion support. Decorative art must never make essential text unreadable.
6. **Performance matters.** Avoid motion, video, filters, and heavy effects that degrade responsiveness. Prefer progressive enhancement and graceful fallback.
7. **Do not ask for more direction if there is enough source material.** Make sensible assumptions, identify them briefly, then implement.

## 2. The six design languages

---

### 01 — Atmospheric Precision
**Influence:** Alan Dye / modern premium interface art direction  
**Character:** Refined, tactile, cinematic, calm, sophisticated.  
**Core idea:** The interface feels like a beautifully crafted object: depth and light make organization intuitive.

- **Composition:** Precise 8-point spacing rhythm; large breathing room; strong alignment; restrained, purposeful surfaces; a calm foreground/background hierarchy.
- **Typography:** Contemporary neutral sans-serif; deliberate typographic scale; crisp labels; limited weights; excellent microtypography.
- **Palette:** Deep graphite `#111827`, ice blue `#9AC7F5`, cloud `#EAF3FC`, white `#FFFFFF`, restrained violet `#8B83DB`. Favor translucent tints over loud blocks.
- **Materials:** Frosted or translucent panels *sparingly*, subtle layering, soft directional shadows, fine dividers, carefully controlled blur and light.
- **Components:** Floating but stable nav, refined cards, quiet segmented controls, pill switches, calm selected states, precise icons and charts.
- **Motion:** Soft spring transitions, short depth cues, subtle reveal and elevation. All motion communicates causality or hierarchy; respect reduced motion.
- **Imagery:** High-quality product imagery, abstract light, soft dimensional gradients; never gratuitous glass on dense forms or tables.
- **Best for:** Premium SaaS, productivity tools, dashboards, product showcases.
- **Avoid:** Glass on every surface; low-contrast translucent text; excessive blur, ornamental animations, or an Apple-interface clone.
- **Pass/fail test:** Even with effects disabled, the page remains polished, readable, and meticulously spaced.

### 02 — Exuberant Expression
**Influence:** Jessica Walsh / colorful expressive brand design  
**Character:** Bold, playful, emotional, joyful, surprising.  
**Core idea:** Personality is a usability tool: memorable imagery and color make the site immediately distinctive.

- **Composition:** Large oversized statements, shifting section rhythms, art-directed shapes, intentional moments of asymmetry anchored by a reliable UI grid.
- **Typography:** An expressive display face paired with a practical body sans; scale contrast; occasional unexpected treatments for headlines, *never* critical controls.
- **Palette:** Electric pink `#FF3864`, orange `#FF8A00`, yellow `#FFD23F`, ultraviolet `#6246EA`, turquoise `#16C9B5`, ink `#211634`. Limit simultaneous accents per section.
- **Materials:** Vibrant color fields, collaged forms, layered cutouts, bold outlines, playful stickers or custom illustrations.
- **Components:** Characterful buttons, delightful hover reactions, expressive feature tiles, boldly framed testimonials, unique but recognizable form states.
- **Motion:** Punchy reveals, small bounces, playful microinteractions; do not distract from completion tasks.
- **Imagery:** Original surreal illustration, unexpected photographic pairings, visual humor and strong art direction.
- **Best for:** Consumer products, creative services, launches, community, playful AI tools.
- **Avoid:** Randomly cycling rainbow colors, novelty type everywhere, illegible layering, childlike treatment for serious workflows.
- **Pass/fail test:** It feels unmistakably energetic while the primary call to action can be found in under three seconds.

### 03 — Interactive Systems
**Influence:** Yugo Nakamura / experimental interactive web work  
**Character:** Curious, intelligent, kinetic, responsive, alive.  
**Core idea:** Behavior—not surface styling—is the signature. The site responds in an intelligible way to exploration.

- **Composition:** Minimal, structured canvas with room for one hero interaction or responsive visualization; reveal supporting material progressively.
- **Typography:** Technical, geometric or neutral sans, generous white space, meticulous small labels, occasionally large conceptual type.
- **Palette:** Midnight `#0F1015`, porcelain `#F6F7F9`, vermilion `#FF513D`, mint `#6EE7B7`, steel `#8B93A5`. Palette is secondary to behavior.
- **Materials:** Thin lines, fields of dots or particles, generative geometry, responsive patterns, restrained contrast.
- **Components:** Interactive visual explorer, filterable information space, responsive diagrams, cursor/touch-driven reactions with a conventional accessible control equivalent.
- **Motion:** State-based transitions, physically coherent movement, responsive generative elements. Make motion directly connected to input; provide pause/reduce alternatives.
- **Imagery:** Procedural graphics, experimental visualizations, systems diagrams; no need for decorative photography.
- **Best for:** AI interfaces, data storytelling, technology demos, research portfolios, interactive explainers.
- **Avoid:** Cursor gimmicks, scroll hijacking, hidden navigation, inaccessible canvas-only interaction, animated backgrounds that obscure tasks.
- **Pass/fail test:** The page is still fully usable with keyboard input and reduced motion, but feels novel when interactions are enabled.

### 04 — Typographic Impact
**Influence:** Paula Scher / bold identity and editorial typography  
**Character:** Confident, architectural, direct, urban, unmistakable.  
**Core idea:** Typography itself supplies structure, rhythm, navigation, and visual drama.

- **Composition:** Large type blocks, poster-like sections, deliberate editorial grids, dramatic changes in scale, strong vertical rhythms.
- **Typography:** Heavy grotesk or condensed display type, emphatic hierarchy, unusual but deliberate line breaks; plain highly readable body copy.
- **Palette:** Signal yellow `#FFD600`, near-black `#111111`, punch red `#EB3F35`, paper `#FAF7F0`; use high-contrast combinations.
- **Materials:** Almost no glossy treatment; flat fields, graphic rules, text-as-shape, selective cropped photography.
- **Components:** Type-led navigation, bold category headers, framed content sections, direct buttons, strong tab labels, oversized numerical callouts.
- **Motion:** Typographic reveals or disciplined directional shifts, but keep text stable during reading.
- **Imagery:** Large-cut photography or minimal visual marks that support—not compete with—the typographic architecture.
- **Best for:** Editorial platforms, events, knowledge products, portfolio sites, cultural and institutional brands.
- **Avoid:** Every line set to giant condensed type, decorative type that reduces scanability, uncontrolled dense text blocks.
- **Pass/fail test:** The information hierarchy remains powerful even when images are removed.

### 05 — Controlled Disruption
**Influence:** David Carson / experimental editorial graphic design  
**Character:** Raw, layered, expressive, imperfect, unexpected.  
**Core idea:** Break visual conventions selectively to add atmosphere and human expression, while retaining a dependable functional spine.

- **Composition:** Broken grids around hero/editorial zones; overlapping headings, textured edges, unconventional cropping. Use a stable underlying grid for navigation and workflows.
- **Typography:** Contrasting type families, selective distressed treatments, angular placements, intentional scale and alignment collisions; practical sans for task text.
- **Palette:** Charcoal `#292524`, parchment `#E7E0D2`, rust `#E14D38`, olive `#8D9469`, muted cobalt `#496A94`.
- **Materials:** Grain, print texture, torn-paper suggestions, editorial photo crops, mixed layering, asymmetric rules.
- **Components:** Expressive feature stories, editorial side notes, high-energy section breaks; conventional accessible menus and forms beneath the art direction.
- **Motion:** Layer shifts, staggered entrances, artful but brief transitions; nothing that interferes with reading or input.
- **Imagery:** Documentary photography, high-contrast crops, text-image interaction, imperfect print-inspired treatment.
- **Best for:** Music, independent culture, storytelling, art portfolios, experimental launches.
- **Avoid:** Illegible body copy, arbitrary disorder, obstructed links or controls, disorder in data-heavy tables, faux grunge on every element.
- **Pass/fail test:** Hero/editorial areas feel rebellious, but users can still complete tasks quickly and confidently.

### 06 — Geometric Wit
**Influence:** Malika Favre / bold geometric illustration and negative space  
**Character:** Clever, optimistic, graphic, crisp, colorful.  
**Core idea:** Simple shapes and negative space communicate sophisticated ideas with minimal visual clutter.

- **Composition:** Clean grid, large clear geometric illustration zones, decisive blocks of color, strong silhouette and whitespace relationships.
- **Typography:** Clean geometric sans with restrained sizes; headlines short, direct, and integrated with illustration rather than competing against it.
- **Palette:** Midnight blue `#172554`, coral `#F43F5E`, sun yellow `#F9CB40`, teal `#0D9488`, warm cream `#FFF8E9`.
- **Materials:** Flat fills, crisp curves, hard-edged silhouettes, contrasting negative space; very little shadow or gradient.
- **Components:** Illustrated concept cards, geometric iconography, color-coded functional sections, strongly legible CTA blocks, playful diagrammatic empty states.
- **Motion:** Simple shape transformations, controlled masking and reveal, gentle parallax only when useful; accessible reduced-motion equivalents.
- **Imagery:** *New* custom geometric compositions and original vector concepts—not reproductions of existing illustrations or specific signature images.
- **Best for:** Educational tools, accessible AI applications, explanatory sites, creative SaaS, editorial storytelling.
- **Avoid:** Generic blobs, overly childish illustrations, too many shapes around text, reliance on color alone to encode information.
- **Pass/fail test:** A screenshot is instantly recognizable for its geometry and visual clarity, not just its color scheme.

## 3. What must vary between the six versions

| Dimension | 01 Atmospheric Precision | 02 Exuberant Expression | 03 Interactive Systems | 04 Typographic Impact | 05 Controlled Disruption | 06 Geometric Wit |
|---|---|---|---|---|---|---|
| Dominant device | Depth & light | Expressive imagery | Responsive behavior | Type scale | Layered composition | Graphic silhouette |
| Layout | Precise, spacious | Rhythmic, surprising | Minimal, exploratory | Editorial, bold | Selectively broken | Clean, illustrated |
| Primary visual | Materialized UI | Saturated art direction | Generative system | Typography | Texture & image crop | Flat geometry |
| Motion | Quiet and tactile | Bouncy and playful | Input-driven | Directed and restrained | Editorial layering | Shape transitions |
| UI treatment | Refined surfaces | Characterful controls | Feedback-forward | Type-first controls | Conventional task spine | Color-blocked, crisp |
| Overall feeling | Premium | Joyful | Inventive | Authoritative | Rebellious | Clever |

**Important:** Merely swapping colors, changing border radii, or using the same component layout with six fonts is a failed result. Build six distinct compositions and interaction grammars.

## 4. Universal design and engineering requirements

- **Content parity:** All six versions must expose the same essential information and actions; no fabricated facts, claims, data, or testimonials.
- **UX parity:** Maintain a comparable path to key tasks and a discoverable primary CTA; preserve search/filter/sort/form operations if present.
- **Responsive:** Design intentional desktop (1440px), tablet (768px), and mobile (390px) behavior. Do not simply shrink a desktop composition.
- **Accessibility:** Semantic HTML, logical heading order, explicit form labels, keyboard navigation, visible focus, sufficient contrast, alt text, and `prefers-reduced-motion` support.
- **System states:** Show hover, focus, selected, error, loading, empty, and success states for relevant controls.
- **Originality:** Create original UI art and shapes. Do not copy source websites or claim the designs are collaborations with the named designers.
- **Implementation:** Use the project's existing stack, components, and design tokens where practical; isolate each version's tokens and styling. Share business logic and data rather than duplicating six independent apps.
- **Maintainability:** Clear names, reusable primitives, no scattered magic numbers, no excessive dependencies, no performance-heavy effects by default.
- **Trade-offs:** If expressive design conflicts with readability or task completion, preserve usability and explain the compromise.

## 5. Exact master prompt to give an AI agent

Copy and customize this prompt:

> You are an expert creative director, product designer, and front-end engineer. Read the attached *Six Design Languages: AI Website Inspiration Playbook* completely.
>
> **Input:** [Attach the existing page, URL, screenshot, Figma link, code, or detailed description.]
>
> **Task:** Create six genuinely distinct, production-plausible visual redesigns of this exact page, using design languages 01–06 from the playbook. These are conceptual directions influenced by broad design philosophies, not imitations of the named designers' specific work.
>
> **Keep constant:** The product's purpose, factual copy and data unless explicitly allowed, information architecture, essential features, navigation destinations, important interactions, and conversion goals.
>
> **Vary aggressively:** Layout, type scale and pairing, spacing, imagery, color, section rhythm, container shapes, components, motion behavior, and visual hierarchy. The options must be visibly different even in grayscale.
>
> **Implement:** Make six working versions (not just moodboards), with a selector/comparison gallery and direct routes or tabs for each. Reuse shared data and logic. Give each version its own scoped design tokens. Ensure desktop, tablet, and mobile support; accessible navigation and focus; reduced-motion behavior; and realistic empty/error/loading states where needed.
>
> **Deliver:** (1) working six-way comparison; (2) name and one-sentence design thesis for each; (3) screenshot or preview for each, if tooling permits; (4) short description of the major visual/interaction decisions; (5) 1–2 usability trade-offs for each; (6) a recommendation of which is strongest for the page's actual audience and task.
>
> **Quality bar:** No six-colorway shortcut. Do not produce near-identical wireframes. Do not sacrifice core workflow usability. The result should feel like six different creative directors interpreted the same brief.

## 6. Review rubric

Score each version from 1 (weak) to 5 (excellent), using the same standard:

| Criterion | Weight | What to look for |
|---|---:|---|
| Distinctiveness | 25% | Clearly different design language; not a reskin |
| Usability | 25% | Primary task intuitive and efficient |
| Craft | 20% | Cohesive typography, spacing, details, state design |
| Accessibility | 15% | Contrast, keyboard, focus, readable layout, motion alternatives |
| Responsive quality | 10% | Strong mobile and desktop compositions |
| Performance | 5% | Motion and visual effects stay lightweight |

**Scoring:** Weighted score = sum of (criterion score / 5) × weight; report as a percentage. First reject versions that fail a critical accessibility or functionality requirement, regardless of score.

## 7. Optional iteration prompts

- **More differentiation:** “These still feel like skins. Change the information composition, visual metaphor, component shapes, and interaction patterns. Preserve workflows.”
- **More practical:** “Apply the same visual language to a dense authenticated screen with filters, tables, menus, errors, and forms.”
- **Mix two directions:** “Create a hybrid: 04's strong typographic hierarchy with 06's geometric illustration. Explain what you kept from each.”
- **Production hardening:** “Take version 02 and remove visual clutter while keeping its joyful identity. Pass WCAG 2.2 AA and mobile performance review.”
- **One-page comparison:** “Show all six at the same viewport width, with identical content and comparable sections, plus side-by-side mobile snapshots.”
