# Demo Library

This directory contains walkthrough documentation, sample data, presentation assets, and golden outputs. Executable browser scripts live in [`../tools/scripts/`](../tools/scripts/).

Demo content is intentionally broader than reusable skills. It may include site setup, prompts, narration, screenshots, generated reports, and reset instructions.
